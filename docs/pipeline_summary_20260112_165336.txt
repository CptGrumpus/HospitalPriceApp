--------------------------------------------------------------------------------
1. For Phase 2 failures:
   - Check if download file exists and is readable
   - Verify file format (CSV/JSON/ZIP)
   - Check file encoding (may need to specify in analyze_csv.py)
   - Review profile file for detailed warnings/errors

2. For Phase 3 failures:
   - Ensure Ollama is running: ollama serve
   - Check profile file for data quality issues
   - Review AI-generated config for validation errors
   - Retry failed hospitals individually

3. For missing hospitals:
   - Verify download completed successfully
   - Check download_manifest.json for file paths
   - Ensure file is in expected location
   - Check analysis_manifest.json for analysis status

4. To retry specific hospitals:
   - Delete their entry from analysis_manifest.json (Phase 2)
   - Delete their entry from config_manifest.json (Phase 3)
   - Re-run the pipeline (it will resume from missing entries)
